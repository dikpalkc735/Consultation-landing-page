# Digital Dikpal consultation landing page

A mobile-first Next.js lead-generation page and matching thank-you page for cold Meta Ads traffic.

## Run locally

1. Install dependencies: `npm install`
2. Start the local server: `npm run dev`
3. Open `http://localhost:3000`

## Connect the form

The consultation form is connected directly to Flodesk form `6ae783ed710a75e6f8beb639`. It submits the field names generated by Flodesk:

- `firstName`
- `email`
- `fields.whatsappNumber`
- `fields.businessName`
- `fields.websiteOrFacebookLink`
- `fields.anythingYouWnatToSay`

After a successful submission, Flodesk redirects to `/thank-you` using the redirect configured in the supplied embed code. Segment membership and workflow automation remain controlled inside Flodesk.

## Deploy to Vercel

1. Push this folder to a Git repository.
2. Import the repository in Vercel; it will detect Next.js automatically.
3. Optionally add `NEXT_PUBLIC_SITE_URL` with the final custom domain. When omitted, Vercel's generated deployment URL is used.
4. Deploy, then submit a real test lead and confirm it reaches the expected Flodesk segment and starts the workflow before sending ad traffic.
